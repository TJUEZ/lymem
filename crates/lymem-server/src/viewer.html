数据集与评测口径
lymem 为本系统；mem0 / iwe 为可本地运行的开源记忆系统，接入同一麒麟嵌入与 MiniMax 生成网关（公平协议）。 整本书问答（三国）为自建中文长文档评测集，BPMN 等其余七站为公开评测集（均含 dev/test 分层划分），明细见 benchmark/data/DATASETS.md； LoCoMo 为公开英文超长对话的免 LLM 严格协议（hit@5，1,986 问全量）；PrefEval / MemBench 为公开基准的必答 MCQ 协议（各 100 题）。 mem0 在七站为同嵌入直插向量口径；其 PrefEval 73.0 / MemBench 55.0 为对齐必答协议后的复测值。
