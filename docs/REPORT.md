## 五、关键发现（写入答辩要点）

1. 检索优化链 47.8%→59.0%：英文停用词（+21pt 纯 BM25）、Snowball 词干化、邻近轮次窗口索引+会话日期注入（+6.9pt）
2. 通道贡献随语料自适应：英文对话 BM25 强、中文/语义查询向量强——固定权重融合次优，图通道在对话语料为负贡献需门控
3. 主流记忆系统（Letta/Cognee/memorax）端侧不可用或重度依赖云端；lymem 全链路端侧+双通道自愈
4. 大规模记忆沉淀：《三国演义》108 回/57.8 万字 532s 灌入，历史事件问答准确并引用回目
