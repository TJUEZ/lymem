# lymem（麟忆尽智）用户手册

本手册面向在银河麒麟桌面 V11 上安装、使用和运维 lymem 的工程师。
三分钟上手路径：装好 → 起 server → 浏览器打开管理界面 → 灌几条记忆 → 搜索。

## 1. 安装

### 1.1 环境要求

- 银河麒麟桌面操作系统 V11（x86_64）
- 系统向量数据库 SDK（kylin-ai-vector-engine）及运行时
- Rust 工具链（仅构建时需要）

### 1.2 构建与安装

```bash
git clone <仓库地址> && cd lymem
cargo build --release
```

构建产物在 `target/release/`：`lymem`（命令行）、`lymem-server`（HTTP 服务）。
可选：拷贝两个二进制到 `~/.local/bin/`，或用 `packaging/` 里的脚本打 deb 包。

### 1.3 启动前检查

```bash
./target/release/lymem status
```

会依次检查：数据目录可写、麒麟 SDK 通道、向量引擎 socket、嵌入模型连通。
哪项不对按提示处理；向量后端可临时切 `LYMEM_VECTOR_BACKEND=sqlite` 开发模式。

## 2. 两种用法

### 2.1 命令行（适合脚本和调试）

```bash
# 接入一条工具执行结果（stdin 传 JSON 事件）
echo '[{"type":"tool_result","data":{"tool":"libreoffice","task":"doc_edit",
"ok":true,"output":"导出 pdf 成功","scene":"office"}}]' | lymem ingest

# 搜索
lymem search "pdf 导出"

# 偏好
lymem pref list                 # 列出全部偏好(带版本)
lymem pref mine-rules           # 规则快通道抓取结果

# 蒸馏：把情景记忆晋升为知识记忆
lymem consolidate

# 经验卡与技能发布（发布前自动编译）
lymem experience compile
lymem experience list
lymem skill targets
lymem skill publish codex

# 遗忘：先预览再执行
lymem forget "忘掉关于doc_edit的一切" --preview
lymem forget "忘掉关于doc_edit的一切" --exec
```

### 2.2 HTTP 服务（给 OS Agent 主程序调用）

```bash
LYMEM_PORT=8801 ./target/release/lymem-server
```

服务起来后：

| 入口 | 用途 |
|---|---|
| `http://127.0.0.1:8801/app` | 统一用户工作台：保存、搜索、修改、删除记忆 |
| `http://127.0.0.1:8801/viewer` | 与 `/app` 完全相同；演示路线可展开评测和治理能力 |
| `http://127.0.0.1:8801/v1/embeddings` | OpenAI 兼容嵌入代理（OS Agent 直接把嵌入基址指过来） |
| `http://127.0.0.1:8801/api/v1/*` | REST API |

## 3. Web 用户工作台

两个入口使用同一份前端，不再区分“日常 App”和“管理 Viewer”。普通用户打开页面后只需要关注四个动作：

1. **保存**：在输入框写下一条内容，点击“保存记忆”。
2. **搜索**：输入关键词，点击“搜索”；清空关键词后点击“全部”恢复列表。
3. **修改**：点击列表中的记忆，在详情面板编辑并保存。修改会生成新版本，旧版本保留在审计链中。
4. **删除**：在列表或详情面板点击“删除”。删除是可审计的软删除，不会把记录静默抹掉。

敏感信息会在保存和修改前经过规则检测，密钥、口令、证件和银行卡信息会被阻断。右下角任务卡会显示正在执行、完成或失败，避免用户点击后不知道是否生效。

## 4. 演示路线与高级能力

按页介绍：

| 页 | 功能 |
|---|---|
| 总览 | 记忆总量、各层分布、检索延迟示波器、操作热力图；首次使用可一键灌入演示数据 |
| 记忆库 | 检索、浏览、详情、AI 问答（答案带引用角标，点角标高亮来源） |
| 偏好 | 偏好列表、版本时间线（每个偏好怎么改的、什么时候改的，一条链看完） |
| 知识与冲突 | 知识列表、实体关系、冲突台账、版本差异、经验卡与技能发布 |
| 遗忘与安全 | 自然语言遗忘：输入指令 → 预览受影响记忆 → 确认执行；敏感文本扫描与脱敏预览 |
| 评测对比 | 内置评测结果、对照条形图和当前活库复测入口 |
| 文件雷达 | 查看记忆相关数据目录和空间占用，执行受控清理 |
| Agent 中枢 | 发现其他 Agent 的摘要、规则和会话历史，预览脱敏后清洗导入，并支持矛盾扫描和受管块分发 |

点击侧栏“演示路线”后，会依次打开高级能力页面并高亮目标控件。这里承接赛题展示所需的多源导入、偏好版本、知识冲突、敏感过滤、效果验证和 Agent 接入；普通用户无需理解这些内部页面。演示模式下每一站会自动高亮目标控件并配一句话说明，ESC 退出。

### 操作反馈

管理台和简化界面都采用统一的任务反馈：点击会触发后端任务的按钮后，按钮会暂时锁定，右下角任务卡会显示当前阶段和进度；完成、失败会分别显示绿色或红色结果，并把摘要留在当前功能区域。导入、检索、文件扫描、遗忘预览/执行、经验编译、技能发布和评测均支持该反馈。长任务期间不要重复点击同一按钮；失败时先阅读任务卡中的接口错误，再重试。

## 5. REST API 速查

```bash
# 接入事件（批量）
curl -X POST http://127.0.0.1:8801/api/v1/memories \
  -H 'Content-Type: application/json' \
  -d '{"events":[{"type":"conversation","data":{"role":"user","text":"…","scene":"office"}}]}'

# 检索
curl "http://127.0.0.1:8801/api/v1/search?query=pdf%E5%AF%BC%E5%87%BA&top_k=5"

# 修改：生成新版本，旧版本保留在历史链
curl -X PUT http://127.0.0.1:8801/api/v1/memories/1 \
  -H 'Content-Type: application/json' \
  -d '{"content":"更新后的记忆内容"}'

# 时点偏好（回到某时刻的偏好集合）
curl "http://127.0.0.1:8801/api/v1/preferences/at?at=2026-09-01T00:00:00Z"

# 审计
curl "http://127.0.0.1:8801/api/v1/audit?limit=50"
```

所有写操作（接入、遗忘、仲裁）都进审计日志，审计页可查。

## 5. 给 OS Agent 主程序的接入建议

1. 嵌入：把 Agent 的 embedding 基址指向 `http://127.0.0.1:8801/v1`，
   模型名任意（服务端固定走麒麟 gte）。
2. 记忆写入：工具执行结束、对话轮次结束、用户改配置时，各推一条事件。
   `scene` 字段填场景名（office / dev / life），检索时会优先同场景。
3. 记忆读取：每次任务规划前调 `/api/v1/search`（top_k 建议 5~10），
   把返回的记忆作为上下文注入提示词。
4. 偏好：启动时拉一次偏好集合，`preferences/at` 支持回溯任意时点。
5. 冲突与遗忘：监听冲突列表接口做人工确认，遗忘用自然语言指令即可。

## 6. 常用环境变量

| 变量 | 说明 | 默认 |
|---|---|---|
| `LYMEM_PORT` | 服务端口 | 8801 |
| `LYMEM_DATA_DIR` | 数据目录 | `~/.local/share/lymem` |
| `LYMEM_VECTOR_BACKEND` | `kylin`（正式）/ `sqlite`（开发降级） | `sqlite`（源码开发默认） |
| `LYMEM_LLM_BASE_URL` / `LYMEM_LLM_API_KEY` / `LYMEM_LLM_MODEL` | 外部 LLM（可选，不配则规则兜底） | — |
| `MEM0_MAX_TOKENS` | 抽取类调用的输出上限 | 16384 |

## 7. 技能编译与 MCP

经验卡可直接编译为 Agent 技能文件，不必每次依赖检索注入。进入 viewer 的「知识与冲突」页，点击「发布技能」会自动执行一次幂等经验编译，再写入目标 Agent 的 `SKILL.md`、`resources/manifest.json` 和版本快照。MCP 端点 `http://127.0.0.1:8801/mcp` 提供 `experience_compile`、`skill_targets`、`skill_publish` 和 `memory_feedback` 工具。完整目录和配置见《技能编译与 Agent 接入》。

## 8. 备份与恢复

数据目录整体拷贝即完整备份（SQLite 单文件 + 引擎侧向量库目录）。恢复 = 停服务、
还原目录、起服务。审计日志随数据目录一起备份。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| `lymem status` 报引擎不通 | 确认 kylin-ai-vector-engine 在跑：socket 缺失时用守护脚本拉起（仓库 `engine-supervisor.sh`） |
| 检索结果不理想 | 先在 viewer 图谱页确认记忆已入库；再试检索开关（加 BM25 / 关图扩展）；`scene` 不对会导致偏好重排偏移 |
| LLM 相关功能没反应 | 未配密钥时系统按设计走规则兜底，属正常；配置后需重启服务 |
| 忘错了想恢复 | 软删走墓碑，审计页可查、可逆；硬清除不可逆 |
