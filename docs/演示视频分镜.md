# 演示视频脚本（总长 8 分钟，可剪辑到 6-7 分钟）

赛方要求：核心功能讲解演示，5-10 分钟，建议配字幕。本脚本按"开场 30 秒 →
真实场景主线 5 分钟 → 评测数据 90 秒 → 收尾 30 秒"组织。每一镜给出画面、
操作、旁白、字幕，照着录即可。

录制前准备：
1. 麒麟 V11 虚拟机或实机，lymem 已构建，8801 服务已起，`LYMEM_VECTOR_BACKEND=kylin`
2. viewer 已打开在总览页；数据库清空（或新用户目录）保证从头演示
3. 屏幕录制 1080p，麦克风另录旁白（后期合成更稳），字幕按本稿
4. 提前演练一遍 06 场景脚本，操作要顺

---

## 镜头 1｜开场（0:00-0:30）

画面：桌面全景，8801 服务在终端里起起来，浏览器打开 viewer 总览页。

旁白：
"这是跑在银河麒麟 V11 上的 OS Agent 记忆系统——麟忆尽智。它管四层记忆：工作、
情景、知识、偏好，检索全走本机的麒麟向量引擎。接下来用三天办公场景，看它怎么
记住、纠错、翻旧账、以及该忘的忘掉。"

字幕：`银河麒麟 V11 · 端侧记忆系统 · 无云依赖`

## 镜头 2｜多源接入与偏好捕捉（0:30-1:40）

画面：切到会话 1。用户对 Agent 说话："以后会议纪要都用简体输出，落款放右下角。"
再演示归档 PDF 的工具执行。

操作：说完后切 viewer 偏好页 → 刷新 → 出现两条新偏好；点开"归档"偏好看版本 v1。

旁白：
"用户随口一句格式要求，偏好快通道毫秒级捕获，写入偏好层。工具执行的结果走另一条
管道，清洗去重后进情景记忆——不同来源，同一个入口。"

字幕：`偏好快通道 · 显式表述毫秒级入库`

## 镜头 3｜知识沉淀：经验卡（1:40-2:40）

画面：viewer 经验卡页，点开新生成的「纪要转PDF归档」经验卡：适用条件、要点、
踩坑三段。

操作：触发一次蒸馏（`lymem consolidate` 或界面按钮），经验卡生成。

旁白：
"试错两次才跑通的做法，被蒸馏成一张经验卡：适用条件、关键命令、踩坑点。下次再
遇到同样任务，Agent 不用再试错。这是知识记忆从情景里长出来的过程。"

字幕：`情景记忆 → 蒸馏 → 经验卡`

## 镜头 4｜冲突调解与版本链（2:40-4:00）

画面：会话 2。用户说："报表还是留 Excel 吧，方便改，别的继续归档 PDF。"

操作：viewer 冲突页 → 出现一条冲突记录 → 打开 diff 视图（`归档=PDF` → `报表=Excel,
其他=PDF`）→ 展示版本链 v1→v2→v3。然后做一次时点查询："我之前是不是说过都要
归档 PDF？"——系统答"是，某月某日，版本 v2"。

旁白：
"偏好变了。系统没有直接覆盖，而是走冲突管道：检测、分类、仲裁，旧值进版本链。
所以它能回答'我之前说过什么'——记忆不但要新，还要经得起翻旧账。"

字幕：`冲突检测 → 仲裁 → 版本链可回溯`

## 镜头 5｜跨会话检索与引用（4:00-5:10）

画面：会话 3。用户："帮我把这季度的会议纪要汇总一下。"

操作：AI 问答给出汇总，答案末尾带引用角标 [1][2]；点击角标，右侧来源记忆卡
高亮闪烁；点开其中一条看全文。切图谱页，输入"会议纪要"，实体关系图展开，
拖拽缩放两下。

旁白：
"三天前的记忆在这里被召回：三份纪要、格式偏好、归档规则。答案的每个结论都能
点回来源——记忆系统不能只是黑盒给答案，得让人核对。图谱页能看到这些记忆之间
的实体关联。"

字幕：`跨会话检索 · 引用可溯源 · 实体图谱`

## 镜头 6｜遗忘与替代陈述（5:10-6:10）

画面：用户："试点项目的数据别再出现在总结里。忘掉试点项目的所有数据记录。"

操作：viewer 遗忘页 → 输入自然语言指令 → 预览受影响记忆清单（高亮若干条）→
确认执行 → 再检索"试点项目"，旧数据已不可见。补充一条"项目已移交"后重新检索，
返回新陈述。

旁白：
"该忘的要忘得掉。遗忘先预览再执行，软删有墓碑可审计。注意最后一步——被遗忘的
位置写入了替代陈述，检索返回的是'项目已移交'，这比单纯删除更接近真实办公需求。"

字幕：`自然语言遗忘 · 预览→执行 · 墓碑可审计`

## 镜头 7｜评测体系与对照数据（6:10-7:30）

画面：viewer 评测页。先扫过七站表，再停在"同后端对照"卡，逐条高亮六条对比
条形（LoCoMo 检索、答案判分、MemBench、PrefEval、LongMemEval、MAB）。最后
切演示模式，让 walkthrough 自动走两步。

旁白：
"评测分两层。检索层用赛题推荐的七个数据集，hit@5 免大模型打分，每道题可人工
复核，召回 95.1%，延迟 24 毫秒，赛题线是 500 毫秒。记忆管理层和 mem0 在同一
麒麟嵌入、同一向量引擎、同一判分模型下对照：冲突整合 22 比 2，端到端判分
33.7 比 23.2。唯一落后的是长程聚合题，我们完成了归因，时间推理单项已经反超。
所有数字逐题落盘，可复算。"

字幕：`召回 95.1%（线 85%）· 延迟 p50 24ms（线 500ms）· 冲突 93.3%（线 88%）`

## 镜头 8｜收尾（7:30-8:00）

画面：回到总览页，热力图和延迟示波器给个全景，慢慢推近。

旁白：
"记得住、分得清、改得对、忘得掉——这是我们对 OS Agent 记忆的定义，也是这套
系统在麒麟桌面上做到的事。谢谢观看。"

字幕：`麟忆尽智 · 银河麒麟 V11`

---

## 录制与剪辑提示

- 每镜操作前先把界面停 1 秒再动，方便剪辑找切点
- viewer 刷新后的加载瞬间剪掉
- 旁白语速放慢 10%，字幕跟着旁白断句
- 若总长超 8 分钟，优先压镜头 3 和镜头 7 的扫过画面
- 导出 mp4（1080p，H.264），确认 zip 后小于 200M
- 全程画面与字幕不得出现姓名、单位（赛方要求）
