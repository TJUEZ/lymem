## 二、麒麟端侧能力适配（条款 4：调用麒麟 embedding SDK）

**嵌入通道（三级自愈）**：

1. **DBus SDK 直连**（首选）：按当前 uid 推导 runtime socket，调用麒麟文本嵌入服务
   （模型 ensemble-embd_gte-base_uint8-text，输出 768 维向量）；
2. **kytensor 直连降级**：DBus 通道异常时自动切 `http://127.0.0.1:8000`（Triton 协议）重试；
3. **本地哈希嵌入兜底**（`LYMEM_EMBEDDER=hash`）：完全离线可用的降级路径。

实测：真机桌面会话中 DBus 通道稳定工作，`status` 报告 `embedder=kylin(auto), embed_dim=768`；
嵌入服务偶发退化时自动重试并降级 kytensor（评审期间真实发生过，未中断服务）。

**嵌入对齐复测**：为让第三方基线（mem0 / memmy）复用同一麒麟嵌入模型保证对比公平，
提供 `/v1/embeddings` OpenAI 兼容代理。mem0 经代理接入后的嵌入向量与 lymem 本地一致
（复测数据见 benchmark/results/REPORT.md §〇一.5）。

**运行身份约束**：麒麟嵌入 SDK 为用户级 DBus 服务，服务必须以**桌面用户身份**运行，
不支持 root 系统服务形态——安装方案据此设计为免 root 用户级部署（见下）。

## 五、离线与数据安全适配（条款 5）

- **敏感信息识别**：纯本地规则引擎（手机号/身份证/银行卡/邮箱/IP 等），无任何外呼；
- **精准遗忘**：自然语言指令→结构化范围（LLM 解析增强，无 LLM 时规则兜底），墓碑/硬清除双档；
- **网络边界**：全服务仅绑定 `127.0.0.1`；唯一外呼点是可选配置的 LLM API（偏好慢通道/冲突仲裁/问答生成），
  **不配置 Key 即完全离线运行**（规则兜底全部功能）；
- **数据落盘**：单文件 SQLite（WAL）+ 全审计留痕，备份 `~/.local/share/lymem` 整目录即可迁移。

## 六、结论

lymem 0.1.0 在银河麒麟桌面操作系统 V11 真机完成端侧适配验证：麒麟 AI 端侧嵌入 SDK
（DBus/kytensor 双通道自愈）、免 root 用户级部署、应用菜单/自启桌面集成、
检索延迟较 500ms 预算留有 94% 以上裕度、可选 LLM 的完全离线运行。**适配结论：通过。**

遗留说明：本机为 x86_64 平台；同代码库面向 ARM64（飞腾/鲲鹏）构建仅涉及 cargo 目标三元组切换，
未在本次测试范围内。
