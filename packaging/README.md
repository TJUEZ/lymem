# 麟忆尽智 lymem · 安装与使用

麟忆尽智（lymem）是运行在麒麟等 Linux 桌面上的 **Agent 端侧长期记忆系统**：
文档与事件多源灌入（自动清洗、分块、贴库标签）、四层记忆流转（工作→情景→知识/偏好）、
偏好双通道自动提取与版本回溯、知识冲突检测仲裁、敏感信息分级与自然语言精准遗忘、
多 Agent 记忆汇聚分发，以及内置数据集的量化评测。全部数据留在本机。

安装后自带 Web 用户工作台：<http://127.0.0.1:8801/app>（`/viewer` 为同一页面，演示路线可展开高级能力）

---

## 安装方式一：deb 包（有 root 权限）

```bash
sudo apt install ./lymem_0.1.0_amd64.deb   # 或 sudo dpkg -i
```

安装内容：`/opt/lymem/`（服务与控制脚本）、应用菜单「麟忆尽智」、图标、
登录自启（`/etc/xdg/autostart`）、配置模板 `/etc/lymem/env`。
卸载：`sudo apt remove lymem`（数据目录保留）。

## 安装方式二：便携包（免 root）

```bash
tar -xzf lymem-0.1.0-linux-amd64.tar.gz
cd lymem-0.1.0-linux-amd64
./install-user.sh          # --no-autostart 可跳过开机自启
```

安装到当前用户 `~/.local/`：菜单项、图标、登录自启、`~/.local/bin/lymem` 命令。
卸载：`./uninstall-user.sh`（保留数据）。

## 开始使用

- **图形方式**：应用菜单 →「麟忆尽智」，自动启动服务并打开管理台；
- **命令方式**：

```bash
lymem open      # 启动服务并打开管理台
lymem status    # 查看运行状态
lymem stop      # 停止服务
lymem logs      # 跟踪日志
```

## 界面操作说明

普通模式打开统一的“我的记忆”工作台，只保留保存、搜索、修改、删除四个动作。点击“演示路线”后再展开评测与集成页面。界面提供 4 套可切换主题（侧栏底部「主题」下拉，
选择即记住）：经典藏青（默认）、清朗白（GitHub 风）、暖纸衬线（Claude 风）、夜间；
也可用 URL 参数直达，如 `http://127.0.0.1:8801/viewer?theme=claude`。
首次演示：进入演示路线后在**总览**页点「灌入演示数据」，
一组隔离在「演示」场景的示例数据（工具轨迹/会话/配置/行为/知识与冲突）即刻入库，
按下面的动线逐页体验；随时可点「清除演示数据」一键回收（真实数据不受影响）。

**① 总览** —— 全局状态与记忆流转。
看四张 KPI（记忆总数 / 知识条目 / 当前生效偏好 / 最近检索延迟，目标 ≤500ms）；
「记忆流转管道」展示 工作→情景→知识/偏好 四层计数，可点「蒸馏一轮」把情景记忆沉淀为知识、
「偏好规则挖掘」从工具使用统计中挖偏好；下方「最近活动」是全部操作的审计留痕。

**② 记忆库** —— 多源灌入与库内问答。
「粘贴文本」：贴任意长文本 → 填库标签（如"办公知识"）→ 灌入，自动清洗/分块/贴标签；
「上传文档」：选 txt/md 文件（小说按"第 N 回"自动分章）；「事件 JSON」：批量导入
工具结果/行为/配置/会话四类结构化事件。「库管理」按标签分组浏览，点条目看详情；
底部检索框即「库内检索问答」：提问后返回带引用的直答与耗时（总览 KPI 同步更新）。

**③ 偏好中心** —— 偏好的自动提取、版本化与回溯。底部「时间机器」：拖动滑块到任意时点，看那一刻的偏好全貌，每条带「现为…/当时才有」差异徽章，可按场景过滤。
顶部两个按钮对应双通道：「规则通道挖掘」（工具使用统计）与「会话通道提取」（LLM 分析
对话中的偏好陈述）；左侧偏好库点任一条，右侧「版本时间线」展示历史版本链
（来源/置信度/适用场景）；「手动设置」可直接写键值，同键重写即追加新版本。

**④ 知识与冲突** —— 工作流/案例/模板的结构化入库与冲突仲裁。
「提取入库」：贴工作流或模板 → 写入即走 检测→分类→仲裁→版本化 四步管道；
「演示冲突：改值重提」：把刚入库的内容改个数字再提交，即刻看到数值冲突仲裁；
「冲突仲裁台账」记录每次新旧知识碰撞；「跨源矛盾」扫描多个 Agent 汇报不一致
（需先在 Agent 中枢导入 ≥2 个源）；「经验复用」卡：点「从近期轨迹编译经验」
把成功/失败轨迹提炼为「做法/避坑」经验卡，复用 ≥2 次且无失败自动转"已验证"，
每张卡可点「用过·成功/失败」反馈。「冲突调解台」把自动仲裁摆给你看：新旧两栏 diff 高亮对比，一键维持新版/恢复旧版/并存/合并，改判随时可再改。

**⑤ 遗忘与安全** —— 精准遗忘四步演示与敏感分级。
第一步「遗忘前检索」留基线 → 第二步输入自然语言遗忘指令 → 第三步「解析并预览」
确认命中范围后执行（软删除可恢复）→ 第四步「遗忘后再检索」前后对比看到记忆消失。
「敏感信息分级」：粘贴任意文本扫描，命中项标红并展示脱敏改写（手机号/密钥/IP 等）。

**⑥ 文件雷达** —— 按内容找文件，不局限于文件名。
先授权目录（默认不索引任何目录，逐目录 opt-in），点「扫描全部目录」把文件内容嵌入索引；
之后在「按内容找文件」里用一句话描述要找的内容（如"讲打印服务器配置的文档"），命中显示
文件与片段，点击看全文。含密钥/密码/身份证/银行卡的文件自动拦截不入库，含手机号/邮箱/IP
的脱敏后入库；删除授权即彻底清除该目录索引。
**⑦ 评测对比** —— 在线量化评测。
「多域预订对话」「BPMN 流程知识」一键对当前库跑 hit@5 + 延迟分位（样例灌入隔离场景，
不动你的库）；「用我自己的数据」粘贴 JSONL（query + 标准答案关键句）评自有文档；
右侧为核心指标达成表；与 mem0/iwe 等同题对比的完整矩阵见提交材料《评测总报告》。

**⑧ Agent 中枢** —— 多 Agent 记忆汇聚、分发与巡检。「记忆关系图谱」把实体共现网络画成可拖拽、可缩放的力导向图，点击实体看它的关联记忆。
「本机记忆源」自动发现本机各终端 Agent 的记忆载体，一键导入全部（清洗分级后入库）；
「库健康」总管巡检（重复指纹/失活记忆/墓碑积压）；「全局关联索引」实体共现自动聚类主题簇；
「记忆分发」选目标 Agent + 检索词，把相关记忆写进其规则文件（只写受管区块，可一键撤回）。
「技能发布」进一步把经验卡与当前偏好编译成标准 `SKILL.md` 技能目录，支持 Codex、
Claude Code、OpenCode、DeepSeek Harness，并保留上一版本用于回滚。

### 五分钟体验动线

总览灌入演示数据 → ②记忆库提问看引用 → ③偏好中心看演示偏好与版本链 →
④知识与冲突看演示冲突台账并「编译经验」→ ⑤遗忘与安全跑四步遗忘 →
⑥评测对比一键出分 → ⑦Agent 中枢点「一键导入全部」。

## 配置（可选）

配置文件：`~/.config/lymem/env`（用户级）或 `/etc/lymem/env`（系统级，deb 安装）。

| 变量 | 说明 | 默认 |
|---|---|---|
| `LYMEM_PORT` | 服务端口 | 8801 |
| `LYMEM_DATA_DIR` | 数据目录 | `~/.local/share/lymem` |
| `LYMEM_LLM_API_KEY` 等 | LLM 网关（Key/BaseURL/Model/Protocol） | 未配置 |
| `LYMEM_EMBEDDER` | `hash` 时用纯 CPU 兜底嵌入 | 麒麟端侧自动 |

不配置 LLM Key 也能使用：灌入、检索、遗忘、评测全部可用；
「检索问答」的生成直答与「会话偏好提取」将走规则兜底（功能演示建议配置）。

## 源码安装复核

源码安装适合开发机和评委复核。仓库根目录执行：

```bash
cargo build --release --locked
LYMEM_PORT=8891 \
LYMEM_DATA_DIR=/tmp/lymem-source-check \
LYMEM_EMBEDDER=hash \
./target/release/lymem-server
```

本项目已复测：构建成功；健康接口返回 `status=ok`；状态接口显示 `hash`、64 维、
`sqlite-vec`、`rules-only`；`/app` 与 `/viewer` 返回 HTTP 200。该路径用于无麒麟运行时的
开发验证，不代表正式端侧性能。银河麒麟验收应使用桌面用户、麒麟 SDK 和 `LYMEM_EMBEDDER=auto`。

## 数据与迁移

全部数据（数据库 + 全文索引）在 `~/.local/share/lymem/`，备份/迁移即整目录拷贝。

## 常见问题

- **点了菜单没反应？** 终端运行 `lymem open` 查看输出；日志在 `~/.local/state/lymem/server.log`。
- **端口被占用？** 在配置文件中改 `LYMEM_PORT`。
- **为什么随桌面用户运行？** 麒麟端侧嵌入按登录用户提供（`/tmp/.kylin-ai-runtime-unix/<uid>/`），
  服务须与桌面同一用户才能使用本地嵌入与 GPU 加速；无人值守场景可在配置中指向
  kytensor HTTP 服务（`LYMEM_KYLIN_KYTENSOR_URL`）或 `LYMEM_EMBEDDER=hash`。

## REST API 与 Agent 接入

服务同时提供本地 REST API（`/api/v1/*`：memories / search / ask / preferences /
knowledge / conflicts / forget / sensitive / arena / experiences / demo / hub …）与
OpenAI 兼容嵌入代理（`/v1/embeddings`），可供本机其他 Agent 接入。

把 lymem 接入 DSH / Cline 等支持 MCP 的 Agent（11 个工具，含经验编译与技能发布）：
见源码包 `integrations/deepseek-harness/README.md`。

命令行除了 `start/stop/status/open/logs` 服务控制命令，还支持 `lymem experience ...`、
`lymem skill ...`、`lymem search` 等记忆操作；安装包会同时提供 `lymem-cli`，由同一个
`lymem` 入口按子命令转发。
